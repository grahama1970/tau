# Canonical DAG Corpus Proof

Tau issue #252 requires more than launch ergonomics. The canonical corpus proof
runs every canonical DAG on the local runtime, reads back the useful output JSON
files that the DAG produced, and runs one deterministic fail-closed control per
DAG.

Run the proof:

```bash
uv run python scripts/prove-canonical-dag-corpus.py \
  --repo . \
  --run-root /tmp/tau-canonical-dag-corpus-proof
```

The aggregate receipt is written to:

```text
/tmp/tau-canonical-dag-corpus-proof/canonical-dag-corpus-proof-receipt.json
```

The receipt reports `mocked: false` and `live: true`. For each positive case it
records:

- the `tau canonical-dag-launch <dag-id>` command used;
- the launched run directory and DAG viewer URL;
- the DAG receipt path;
- the useful output artifact paths read from the filesystem;
- the artifact schemas and goal hashes that were checked.

For each negative case it records:

- the real-world sanity negative-control command used;
- the blocked receipt path;
- the observed blocked status and verdict;
- the exact fail-closed verdict expected for that DAG.

This proof establishes that the five canonical DAGs produce recognizable local
outputs and have deterministic failure paths. It does not establish dynamic
browser rendering, final human acceptance, or full crash-safe targeted repair
beyond the recovery receipts generated by these canonical DAGs.
